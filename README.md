# Classic Tanks

Open-source cross-platform browser tank game focused on fair competitive gameplay, readable mechanics, and server-authoritative architecture.

## Project status

**Phase 0 — Foundation**

The project is currently in repository and development-environment preparation. Production gameplay implementation has not started yet.

## Vision

Classic Tanks is a browser-based team tank game designed around readable arcade gameplay, meaningful vehicle roles, fair matchmaking, server-authoritative simulation, and broad cross-platform support.
