# Game Design Overview

## Vision

Classic Tanks is a browser-based team tank game built around readable arcade combat, distinct vehicle roles, fair competitive conditions, and gradual mastery.

## Core pillars

1. Skill should matter more than arbitrary randomness.
2. The server is authoritative for competitive outcomes.
3. Visual quality must not create gameplay-information advantages.
4. Matchmaking should seek comfortable and fair battles rather than mechanically identical teams.
5. The interface should start simple and remain deeply customizable.
6. Systems should be validated through prototypes before being over-engineered.

## Current scope

The complete design baseline is being transferred from the project design discussions into focused documents. The vertical slice will intentionally implement only the minimum combat loop needed to validate the core feel.
