# Balancing

Balance work should be evidence-driven.

## Principles

- Do not tune complex formulas before the underlying mechanic is playable.
- Separate observed data from design assumptions.
- Record significant balance changes and why they were made.
- Prefer short controlled experiments over large simultaneous changes.
- Use time-windowed player statistics (including 30, 90, and 180 days) when the relevant system reaches production readiness.

## Phase 0

No balance system is being implemented yet. The folder establishes the future location for balance experiments and validated decisions.
