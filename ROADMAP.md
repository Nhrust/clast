# Roadmap

## Phase 0 — Foundation

Repository, documentation, development conventions, CI, local tooling, and architecture baseline.

## Phase 1 — Vertical Slice v0.1

One test map, 2–3 test tanks, browser client, WebSocket connection, authoritative movement, aiming, shooting, HP, damage, destruction, and basic synchronization.

## Phase 2 — Core Combat

Armor, penetration, ricochet, ammunition, reload, modules, repair kit, projectile model, and arcade physics.

## Phase 3 — Visibility

View range, concealment, bushes, detection, delayed information sharing, minimap, and server-side ESP protection.

## Phase 4 — Maps

Production-quality maps, spawn logic, routes, class interactions, and map-specific balance testing.

## Phase 5 — Matchmaking

Queues, skill protection, platoons, ping-aware matching, map-aware team composition, bots, and search expansion.

## Phase 6 — Progression

Vehicle tiers I–V, research, XP, nations, economy, and 30/90/180-day plus lifetime statistics.

## Phase 7 — Social

Friends, platoons, clans, clan 7×7 mode, communication, reports, and community tooling.

## Phase 8 — Security & Analytics

Server validation, anti-cheat tooling, minimal telemetry, moderation tools, and debug replay data.

## Phase 9 — Performance

Low-end hardware testing, network-condition testing, client optimization, server profiling, and scalability validation.

## Phase 10 — Open Beta

Public testing, feedback, balancing, stability, moderation, and operational readiness.

## Phase 11 — Production

Multi-server deployment, regional infrastructure, monitoring, backups, and controlled scaling.

## Future

Additional maps, nations, vehicle branches, seasons, fan modes, cosmetic/supporter content, and full user replay functionality.

## Guiding rule

Validate the smallest playable system before building large-scale infrastructure around assumptions.
